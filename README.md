# MoodSpace

**MoodSpace** is a bilingual (Traditional Chinese / English), privacy-first free practice room for emotional clarity and small actions.

No accounts, no tracking, no data uploaded. Everything stays in your browser.

Inspired by self-guided mental health tools (e.g. CBT-style exercises, needs clarification, boundary practice). Designed with Hong Kong users in mind (local emergency and support numbers).

## Features

- **~50 self-guided tools** across categories:
  - Organize emotions & thoughts
  - Practice expression & communication
  - Start a small action
  - Just pause (no writing)
  - Prepare for help & support
- Step-by-step wizards that generate a copyable / printable card
- Mood tracker (local only)
- Guided “don’t know where to start” entry
- Dark mode + language toggle
- Glossary of common psychology terms
- Hong Kong support resources
- Fully offline-capable after first load

## Privacy

All inputs stay in the browser (localStorage for preferences and mood tracker only). Nothing is sent to any server.

## How to use

1. Open the site (or open `index.html` locally).
2. Pick a tool, or answer the guided questions.
3. Follow the steps. Skip anything you don’t want to fill.
4. Copy or print the resulting card if you want to keep it.

## Deploy

### GitHub Pages (recommended)

1. Go to the repository **Settings → Pages**.
2. Source: Deploy from a branch → `main` / `/ (root)`.
3. Save. The site will be available at `https://ivanmang.github.io/moodspace/`.

### Local

Just open `index.html` in a browser. No build step required.

## Disclaimer

These tools are for self-guided practice only. They are **not** therapy, counseling, diagnosis, or crisis support.

If you are in immediate danger, call **999**. For emotional support in Hong Kong: **18111** (24h).
